# DOCUMENTO 5 — Checklist diário

Imprima. Cole na mesa. Ou abra no celular.

---

## ☀️ AO CHEGAR — até as 09:00

```
☐ Marquei presença ("Cheguei")          → sem isso não recebo lead nenhum
☐ Declarei as metas do dia no popup     → agendamentos · documentações · vendas da semana
☐ Abri /fila e li o placar              → vencidos · vencem hoje · sem próximo passo · em jogo
☐ Olhei a Agenda de hoje                → sei quais visitas preciso confirmar
```

## 🔥 ANTES DAS 10:30 — o dinheiro na mesa

```
☐ Toquei TODO card do "Fundo do funil parado"
    ☐ análises de crédito: cobrei cliente E Caixa
    ☐ visitas realizadas: pasta encaminhada
    ☐ agendados: visita confirmada (D-2 / D-1 / D+0)
☐ Atendi TODO lead de "Chegaram agora" em até 15 min úteis
☐ Respondi TODO card de "Cliente respondeu e espera"
☐ Registrei o desfecho de cada um deles
```

## 📞 ANTES DO ALMOÇO — a régua

```
☐ Zerei "Follow-up vencido ou de hoje"
☐ Ataquei "Sem próximo passo"
☐ Nenhum card foi fechado sem [Registrar]
```

## ⚡ DURANTE O DIA — as 5 regras que não se quebram

```
☐ Registrei TODA interação pelo desfecho de um toque
☐ TODO lead que toquei saiu com próximo passo E data
☐ Ofereci visita em TODA conversa ativa (duas opções de horário)
☐ Toda visita marcada virou AGENDAMENTO no CRM, não só mudança de status
☐ Todo lead morto virou "perdido" com uma das 11 categorias de motivo
```

## 🚀 SE A FILA ACABAR — nunca ficar parado

```
☐ Reserva     → resgatei leads (até 13)
☐ Modo Foco   → trabalhei um lote de aguardando atendimento
☐ Discador    → bloco de 30–45 min, TABULEI toda ligação
☐ Bolsão      → "já houve conversa" primeiro
☐ Oferta Ativa → disparei lista segmentada
```

## 🌙 ANTES DE IR EMBORA — 17:30, inegociável

```
☐ Placar "Sem próximo passo" = 0
☐ Placar "Vencidos" = 0
☐ Nenhum lead novo sem atendimento
☐ Nenhum cliente do fundo do funil sem retorno hoje
☐ Visitas de amanhã confirmadas
☐ Perdidos do dia marcados com motivo
☐ Documentos recebidos hoje registrados na pasta
☐ Conferi meu placar do dia × meta declarada
☐ Olhei a agenda de amanhã
```

---

## 📊 O PLACAR MÍNIMO DO DIA

Marque o que você fez. Se as três primeiras linhas não fecharem, o dia não fechou.

| Indicador | Mínimo/dia | Fiz |
| --- | ---: | :-: |
| **Desfechos registrados** (o indicador-mãe) | **20** | ☐ |
| **Leads tocados** (WhatsApp ou ligação) | **25** | ☐ |
| Conversas efetivas (o cliente respondeu) | 8 | ☐ |
| **Agendamentos criados** | **1,4** → 7/semana | ☐ |
| Documentações recolhidas | 1 | ☐ |
| Análises de crédito enviadas | 0,7 → 3,3/semana | ☐ |
| Follow-ups vencidos ao fim do dia | **0** | ☐ |
| Leads sem próximo passo ao fim do dia | **0** | ☐ |
| Perdidos marcados com motivo | todos | ☐ |

Base dos números: [Documento 8](08-indicadores.md).
