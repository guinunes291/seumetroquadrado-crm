# Apresentação — Manual do CRM SMQ

`Manual-CRM-SMQ.pptx` · 20 slides · ~35 min de apresentação · **notas do apresentador em
todos os slides**.

Para o time de corretores. Gerado por `gerar-deck.js` (pptxgenjs) — para mudar um número
ou um texto, edite o script e rode `node gerar-deck.js`, em vez de editar o `.pptx` à mão.

PowerPoint antes de projetar.
